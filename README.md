# C++

| Path | What |
|---|---|
| `c++conspect.md` | Official theme list (1–55) |
| `practice/` | One file per theme. Filename prefix = theme number |
| `exam_task/` | Exam statements (`.md`) and solutions (`.cpp`). Same basename = same task |
| `themes_explained_without_Net.md` | Theme notes, .NET parts dropped |
| `themes_explained_without_Net_better_version.md` | Same, cleaner rewrite |

Compile a practice file with:

```bash
c++ -std=c++17 -o /tmp/run practice/16_virtualization.cpp && /tmp/run
```

Binaries next to sources are gitignored.
